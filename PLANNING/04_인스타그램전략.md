# 4. 인스타그램 발견 전략

인스타그램에서 발견한 장소 정보를 PlaceCard로 변환하는 전략입니다.

---

## 4.1 인스타그램 데이터 접근의 한계

### 공식 API의 제약

| 채널 | 지원 여부 | 이유 |
|------|---------|------|
| **Instagram Graph API** | ❌ 불가 | 위치태그, 캡션 전체 텍스트 미지원 (기본 정보만) |
| **oEmbed API** | ❌ 불가 | 위치명, 캡션 전부 가져올 수 없음 |
| **web.instagram.com 크롤링** | ❌ 금지 | ToS 위반, JavaScript 렌더링 필요 |

### 기술적 한계

- Instagram은 JavaScript로 동적 렌더링 → 정적 크롤링 불가
- 위치태그는 HTML에 불완전하게만 노출
- 캡션의 은어, 해시태그와 일반 텍스트 구분 어려움

---

## 4.2 채택된 설계: \"발견 → 검증\" 2단계 구조

### 아키텍처

```
┌─────────────────────────────────┐
│   1. 발견 (Discovery)           │
│   사용자가 스크린샷 추가          │
└────────────────┬────────────────┘
                 ↓
         ┌──────────────────┐
         │ Claude API       │
         │ (Vision+Text)    │
         │ 이미지+캡션 분석  │
         └────────┬─────────┘
                  ↓
    ┌────────────────────────────┐
    │ 추출 결과                    │
    │ • 위치명 후보 [A, B, C]      │
    │ • 신뢰도 [0.95, 0.80, 0.65] │
    │ • 보충 정보                  │
    └────────────┬────────────────┘
                 ↓
    ┌────────────────────────────┐
    │ 2. 검증 (Verification)     │
    │ 사용자 확인                  │
    │ \"이 위치 맞나요?\"          │
    └────────────┬────────────────┘
                 ↓
    ┌────────────────────────────┐
    │ Google Places API          │
    │ 최종 데이터 조회 & 저장      │
    └────────────┬────────────────┘
                 ↓
    ┌────────────────────────────┐
    │ PlaceCard 생성 완료         │
    │ discoverySource: Instagram  │
    └────────────────────────────┘
```

## 4.3 Claude API를 쓰는 이유

단순 OCR과 비교:

| 기능 | 단순 OCR | Claude Vision API |
|------|---------|------|
| 텍스트 인식 | ✅ | ✅ |
| 은어/줄임말 해석 | ❌ | ✅ (예: \"감자탕 맛집\" → 감자탕 전문점) |
| 해시태그와 일반 텍스트 구분 | ❌ | ✅ |
| 여러 장소 언급 시 분리 | ❌ | ✅ |
| 신뢰도 스코어 제공 | ❌ | ✅ (예: confidence 0.95) |
| 컨텍스트 이해 | ❌ | ✅ (사진 내용과 캡션 함께 분석) |

### 예시

**입력**:
- 인스타그램 스크린샷 (카페 사진 + 위치 표시)
- 캡션: \"여기 계절메뉴 미쳤다!! 🤤 #강남카페 #감성카페\"

**Claude API 응답**:
```json
{
  "extracted_locations": [
    {
      "name": "추출된 위치명 (있으면)",
      "confidence": 0.85,
      "reason": "스크린샷에 위치명이 있지만, 정확한 매칭을 위해 검증 필요"
    }
  ],
  "inferred_location_candidates": [
    {
      "name": "강남역 근처 감성 카페 A",
      "confidence": 0.75,
      "based_on": "캡션의 위치 해시태그 + 사진 스타일"
    },
    {
      "name": "강남역 근처 감성 카페 B",
      "confidence": 0.60,
      "based_on": \"유사한 인테리어\"
    }
  ],
  "caption_summary": "계절 메뉴가 특징인 감성 카페",
  "analysis_confidence": 0.72
}
```

## 4.4 BYOK (Bring Your Own Key) 모델

### 정책

**사용자가 자신의 Anthropic API 키를 등록하여 직접 청구**

```
사용자
  ↓ (Anthropic 계정 생성 + API 키 발급)
앱 내 설정에서 API 키 입력
  ↓
Keychain에 안전히 저장
  ↓
이미지 분석 필요 시 사용자 키로 Claude API 호출
  ↓
비용: 사용자가 Anthropic 계정에서 확인
```

### 장점

- **앱 운영자 비용**: 0원 (모든 API 비용을 사용자가 부담)
- **사용자 투명성**: Anthropic 콘솔에서 직접 사용량 및 비용 확인 가능
- **개인정보 보호**: 이미지가 앱 회사 서버를 거치지 않고 사용자 키로 직접 Anthropic에 전송
- **확장성**: 수억 개의 요청을 감당할 수 없는 비용 문제 해결

### 보안 원칙

```swift
// ✅ 올바른 저장소
Keychain.store(
    key: \"anthropic_api_key\",
    value: userInput,
    accessibility: .whenUnlockedThisDeviceOnly  // 기기 잠금해제 시에만 접근
)

// ❌ 금지
UserDefaults.standard.set(apiKey, forKey: "api_key")  // 평문 저장 금지
```

## 4.5 Claude API 호출 흐름

### Step 1: 사용자 설정 (온보딩)

```
[설정 화면]
├─ "Claude API 키 등록" 버튼
└─ 입력 필드 + 검증 버튼
   ↓
[검증: Claude API에 헬스체크]
   ↓
[Keychain에 저장 (성공 시)]
```

### Step 2: 스크린샷 분석 (인스타그램)

```
[사용자가 인스타그램 스크린샷 추가]
  ↓
[다이얼로그: \"이 사진을 분석하시겠어요?\"]
[예상 비용: ~$0.01]
  ↓
[Claude API 호출]
POST https://api.anthropic.com/v1/messages
{
  \"model\": \"claude-3-5-sonnet-20241022\",
  \"max_tokens\": 1024,
  \"messages\": [
    {
      \"role\": \"user\",
      \"content\": [
        {
          \"type\": \"image\",
          \"source\": {
            \"type\": \"base64\",
            \"media_type\": \"image/jpeg\",
            \"data\": \"<base64 encoded image>\"
          }
        },
        {
          \"type\": \"text\",
          \"text\": \"이 이미지에서 카페/음식점 등의 위치명을 찾아주세요. ...\"
        }
      ]
    }
  ]
}
  ↓
[응답 파싱]
  ↓
[사용자에게 후보 제시]
```

### Step 3: 사용자 검증

```
[화면: \"이 위치 맞나요?\"]
├─ Claude가 추출한 위치명 후보들
├─ 신뢰도 점수
└─ \"수동 입력\" 버튼
  ↓
[사용자가 선택]
  ↓
[Google Places API로 최종 검증]
```

## 4.6 Claude API 프롬프트 설계

### 프롬프트 템플릿

```
당신은 인스타그램 스크린샷에서 카페, 음식점, 관광지 등의 위치명을 추출하는 AI 어시스턴트입니다.

## 작업
1. 이미지에 보이는 위치명을 찾으세요. (텍스트, 로고, 위치 태그 등)
2. 이미지의 컨텍스트(인테리어, 음식, 위치 해시태그)를 분석해서 위치명을 추론하세요.
3. 각 후보의 신뢰도를 0.0~1.0 사이의 점수로 표기하세요.

## 응답 형식 (JSON)
{
  \"extracted_locations\": [
    {
      \"name\": \"위치명\",
      \"confidence\": 0.95,
      \"source\": \"이미지에 직접 표시됨\"
    }
  ],
  \"inferred_locations\": [
    {
      \"name\": \"추론된 위치명\",
      \"confidence\": 0.75,
      \"reason\": \"추론 근거\"
    }
  ],
  \"caption_summary\": \"캡션의 요약\",
  \"recommendation\": \"사용자에게 할 조언\"
}

## 주의사항
- 정확하지 않은 추측은 신뢰도를 낮게 책정하세요.
- \"강남역 근처 카페\" 같은 모호한 표현은 피하고 구체적 명칭을 찾으세요.
- 여러 장소가 나오면 모두 나열하세요.
```

## 4.7 사용자 정책 옵션

```swift
enum AIAnalysisPolicy: String {
    case always         // 스크린샷 추가 시 자동 분석
    case askEachTime    // 매번 확인 다이얼로그 (기본값, 권장)
    case manualOnly     // AI 미사용, 수동 입력만
}
```

**기본값**: `askEachTime` (투명성 + 비용 제어)

**화면 예시**:
```
─────────────────────────────────────
💬 위치 분석
─────────────────────────────────────

이 스크린샷의 위치명을 Claude AI로
분석하시겠어요?

예상 비용: ~$0.010
(사용자의 Anthropic 계정으로 청구됨)

[취소]  [분석하기]
─────────────────────────────────────
```

| 오류 | 사용자 경험 |
|------|----------|

| 네트워크 오류 | 재시도 버튼 제공 |

## 4.9 비용 추정

### Claude 3.5 Sonnet 가격 (2026년)

| 비용 항목 | 가격 |
|---------|------|
| 입력 토큰 | $0.003 / 1M tokens |
| 출력 토큰 | $0.015 / 1M tokens |
| Vision 이미지 | $0.075 / image (일부 가격 포함) |

### 인스타그램 스크린샷 1장 분석 비용

```
입력:
  - 이미지: ~200KB (base64 인코딩 후 ~270K chars) ≈ 675 tokens
  - 프롬프트: ~300 tokens
  입력 합계: ~1,000 tokens

출력:
  - JSON 응답: ~200 tokens

전체 비용:
  = (1,000 × 0.003 + 200 × 0.015) / 1,000,000
  = (3 + 3) / 1,000,000
  ≈ $0.000006 (약 0.6센트, 매우 저렴)
```

**월 1,000건 분석 시**: 약 $6

## 4.10 프라이버시 고려사항

### 데이터 흐름

```
사용자 기기
  ↓ (HTTPS, 사용자 API 키)
Anthropic Claude API
  ↓
분석 결과만 반환
  ↓
사용자 기기에서 PlaceCard 생성
  (이미지는 로컬에만 저장, 앱 회사 서버 경유 안 함)
```

### Privacy Policy 명시 필요 사항

- ✅ \"인스타그램 스크린샷은 Anthropic(Claude API)의 Vision 분석을 통해 처리됩니다.\"
- ✅ \"이미지는 Anthropic과 공유되며, 이들의 Privacy Policy를 따릅니다.\"
- ✅ \"분석 결과만 앱에 저장됩니다. 이미지 자체는 Anthropic의 정책에 따라 처리됩니다.\"
