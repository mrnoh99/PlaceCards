## 6.2 데이터 흐름

### 플로우 1: 지도 스크린샷 추가

```
[사용자가 갤러리에서 스크린샷 선택]
         ↓
[Vision Framework로 텍스트/영역 추출]
    (ScreenshotScanService)
         ↓
    위치명, 주소 등 추출됨
         ↓
[Google Places API로 검증]
    (GooglePlacesService)
         ↓
   ✓ 매칭 성공 → 상세 정보 수신
   ✗ 매칭 실패 → 사용자에게 수동 입력 요청
         ↓
[PlaceCard 생성 (Codable)]
         ↓
[SwiftData에 저장]
    (LocalStorageService)
         ↓
[UI 업데이트]
    (PlaceCardVM)
```

### 플로우 2: 인스타그램 스크린샷 (Claude 분석)

```
[사용자가 인스타그램 스크린샷 추가]
         ↓
[설정에서 분석 정책 확인]
    (UserDefaults)
         ↓
   policy == .askEachTime?
   ├─ YES → 다이얼로그 표시 (\"분석하시겠어요?\")
   └─ NO → 자동 진행
         ↓
[Keychain에서 Claude API 키 로드]
    (KeychainService)
         ↓
[이미지를 base64로 인코딩]
         ↓
[Claude API 호출 (Vision)]
    (ClaudeDirectService)
         ↓
   위치명 후보 + 신뢰도 반환
         ↓
[사용자에게 후보 제시 + 확인]
         ↓
[Google Places API로 최종 검증]
         ↓
[PlaceCard 생성]
         ↓
[SwiftData에 저장]
```

### 플로우 3: Naver 스크린샷 + Naver API 보강

```
[사용자가 네이버 지도 스크린샷 추가]
         ↓
[Vision으로 텍스트 추출]
         ↓
[Naver API 호출 (백엔드 프록시 경유)]
    POST /api/naver/search
         ↓
[프록시에서 Naver API 응답 중계]
    (Client Secret을 프록시에서만 보유)
         ↓
[결과를 PlaceCard에 통합]
         ↓
[추가로 Google Places API로 상세정보 보강]
         ↓
[저장]
```

### 재시도 로직

```swift
func retryWithExponentialBackoff<T>(
    maxRetries: Int = 3,
    operation: () async throws -> T
) async throws -> T {
    var lastError: Error?
    
    for attempt in 0..<maxRetries {
        do {
            return try await operation()
        } catch {
            lastError = error
            let delay = pow(2.0, Double(attempt))
            try await Task.sleep(nanoseconds: UInt64(delay * 1_000_000_000))
        }
    }
    
    throw lastError ?? PlaceCardsError.networkError("Max retries exceeded")
}
```

### 데이터 로딩 (Lazy Loading)

```swift
@MainActor
class GalleryViewModel: ObservableObject {
    @Published var placeCards: [PlaceCard] = []
    private var allCards: [PlaceCard] = []
    private let pageSize = 20
    
    func loadMore() async {
        let nextIndex = placeCards.count
        let endIndex = min(nextIndex + pageSize, allCards.count)
        placeCards.append(contentsOf: allCards[nextIndex..<endIndex])
    }
}
```
