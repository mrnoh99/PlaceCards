# PlaceCards: 외부 지도 앱에서 내보내기 (사용자 가이드)

사용자가 Google Maps, Naver Map에서 장소를 PlaceCards로 가져오는 방법 정리

---

## 1. Google Maps에서 내보내기 (3가지 방법)

### 방법 1️⃣: Google Takeout (공식 방법 - 추천)

**장점**: 모든 저장된 장소 한번에 내보내기

**단계**:
1. 브라우저에서 **takeout.google.com** 접속
2. "Select data to include" → **Google Maps** 체크
3. Format: **JSON** 선택
4. "Next step" → Download (.zip 파일)
5. 다운로드 완료 후 `.zip` 파일 확인

**받는 파일**:
```
takeout-{날짜}.zip
└─ Takeout/Google Maps/
   └─ Saved Places.json (또는 여러 JSON 파일)
```

**PlaceCards에서 가져오기**:
1. PlaceCards 앱 열기
2. [Settings] → [Import] → [JSON File 선택]
3. 다운로드한 `Saved Places.json` 선택
4. 자동으로 모든 장소가 PlaceCard로 변환됨 ✅

---

### 방법 2️⃣: Google Maps 공유 버튼

**장점**: 한 장소씩 바로 연동

**단계**:
1. Google Maps 앱에서 원하는 장소 검색
2. 장소 상세 정보 페이지 열기
3. **공유** 버튼 클릭
4. **PlaceCards** 선택 (목록에 없으면 "더보기")
5. 자동으로 PlaceCard 생성 ✅

**어떻게 작동하나**:
```
Google Maps [공유] → iOS Share Sheet → PlaceCards
  ↓ (URL로 정보 전달)
PlaceCards가 Google Places API로 상세 정보 조회
  ↓
PlaceCard 자동 생성
```

---

### 방법 3️⃣: Google Maps URL 복사

**장점**: 수동 제어, 여러 URL 한번에

**단계**:
1. Google Maps에서 장소 검색
2. 주소창 URL 복사
3. PlaceCards 앱에서 [Add] → [Paste URL]
4. 자동으로 PlaceCard 생성 ✅

**URL 형식**:
```
https://www.google.com/maps/place/스타벅스+강남역점/@37.4979,127.0663
또는
https://maps.app.goo.gl/ChIJ1234567890
```

---

## 2. Naver Map에서 내보내기 (2가지 방법)

### 방법 1️⃣: Naver Map 공유 버튼 (추천)

**장점**: 가장 간단함

**단계**:
1. Naver Map 앱에서 원하는 장소 검색
2. 장소 상세 정보 페이지 열기
3. **공유** 버튼 클릭
4. **PlaceCards** 선택
5. 자동으로 PlaceCard 생성 ✅

**특징**:
- Naver 정보 (이름, 주소, 전화, 카테고리)가 저장됨
- PlaceCards는 자동으로 Google Places API로 상세정보 보강
- 평점, 리뷰, 영업시간 등이 추가됨

---

### 방법 2️⃣: Naver Map URL 복사

**단계**:
1. Naver Map에서 장소 검색
2. 주소창 URL 복사
3. PlaceCards [Add] → [Paste URL]
4. 자동으로 PlaceCard 생성 ✅

**URL 형식**:
```
https://map.naver.com/v5/search/스타벅스+강남역점
또는
nmap://place?id=12345678
```

---

## 3. 여러 장소를 한번에 (Google Takeout만 지원)

### Google Takeout JSON 배치 임포트

**상황**: 여행 계획한 50개 장소를 모두 추가하고 싶은 경우

**단계**:
1. Google Maps에서 새 리스트 생성 ([+] → "새 리스트" 또는 "아고 싶은 곳")
2. 50개 장소를 이 리스트에 저장
3. [Settings] → [Import] → [Google Takeout 선택]
4. takeout.google.com에서 이 리스트만 내보내기
5. `.zip` 파일 다운로드
6. PlaceCards: [Settings] → [Batch Import]
7. JSON 파일 선택
8. ⏳ 자동으로 모든 장소가 추가됨 (진행률 표시)

**예상 시간**:
- 50개 장소: ~30초
- 100개 장소: ~1분
- 500개 장소: ~5분

## 5. 트러블슈팅

### Q1: "PlaceCards가 공유 옵션에 나타나지 않음"

**원인**: PlaceCards가 URL 또는 텍스트를 받을 수 있도록 등록되지 않음

**해결**:
```
Settings 앱 → [PlaceCards] → [공유 및 협업] → 허용
또는
iOS 15+ 사용 확인
```

---

### Q2: "Google Takeout JSON을 선택했는데 안 됨"

**원인**: 파일 형식이 잘못되었거나 손상됨

**확인**:
```
1. 파일 이름이 "Saved Places.json" 또는 ".json"으로 끝나는지 확인
2. 압축 해제가 제대로 되었는지 확인
3. 파일을 텍스트 에디터로 열어 유효한 JSON인지 확인
```

**다시 시도**:
1. takeout.google.com 재방문
2. 다시 내보내기
3. PlaceCards에서 다시 임포트

---

### Q3: "Naver Map에서 내보낸 장소의 정보가 부족함"

**이유**: Naver Map API는 Google보다 정보가 적음 (평점, 리뷰 없음)

**해결**: PlaceCards가 자동으로 Google Places API로 보강함
```
Naver에서 가져온 정보:
  ✓ 이름, 주소, 좌표
  ✓ 전화번호, 카테고리

PlaceCards가 자동 추가:
  ✓ 평점, 리뷰 수
  ✓ 영업시간, 편의시설
  ✓ 웹사이트, 사진
```

---

### Q4: "여러 장소를 한번에 추가하고 싶음"

**Google Takeout 배치 임포트만 지원**:

**단계**:
1. Google Maps에서 새 리스트 만들기 (예: "2026년 강남 여행")
2. 모든 장소를 이 리스트에 추가
3. Google Takeout에서 이 리스트 내보내기 → `.zip`
4. PlaceCards [Settings] → [Import] → [Batch Import]
5. JSON 파일 선택 → 모든 장소 자동 추가 ✅

## 6. 데이터 보안

### PlaceCards는 어떻게 데이터를 다루나?

✅ **안전**:
- 모든 데이터는 **기기 내 저장** (클라우드 업로드 안 함)
- Google Takeout 파일은 다운로드 후 **사용자만 접근 가능**
- PlaceCards는 기기 내에서만 파일 읽기 수행

⚠️ **주의**:
- 만약 Google Maps 공개 링크를 공유했다면, 이미 공개된 상태
- Google Takeout 파일에는 모든 저장된 장소가 포함되므로 공유 주의

## 7. FAQ

### Q: 기존 Google Maps에 저장된 장소를 PlaceCards에 모두 옮기려면?
**A**: Google Takeout 배치 임포트 사용
1. takeout.google.com → Google Maps 모두 선택
2. JSON 다운로드
3. PlaceCards [Batch Import] → 완료!

---

### Q: Naver Map "내 장소" 폴더를 PlaceCards로 가져올 수 있나?
**A**: 아직 비공식 방법만 가능
- Naver Map은 공식 내보내기 기능 없음
- 각 장소를 하나씩 공유하거나 URL로 복사
- 향후 Naver API 지원 예정

---

### Q: PlaceCards에서 역으로 Google Maps로 내보낼 수 있나?
**A**: 계획중 (v1.2+)
- 현재: PlaceCards → JSON/CSV 내보내기만 가능
- 향후: Google Maps와 양방향 동기화 검토
