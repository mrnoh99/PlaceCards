# PlaceCards: 외부 지도 앱 연동 가져오기 기획

Google Maps, Naver Map에서 검색한 장소를 PlaceCards로 가져오는 전체 흐름을 설계합니다.

---

## 1. 전체 흐름도

```
┌─────────────────────────────────────────────────────────────┐
│                   사용자의 흐름                              │
└─────────────────────────────────────────────────────────────┘

1️⃣ Google Map에서 검색
   └─ "스타벅스 강남역점" 검색
   └─ 저장 (Saved Places)

2️⃣ 내보내기 선택
   ├─ Google Takeout으로 내보내기 (JSON)
   ├─ 또는 공유 버튼 → PlaceCards 앱
   └─ 또는 URL 스키마로 직접 연결

3️⃣ PlaceCards 앱으로 가져오기
   ├─ JSON 파일 분석
   ├─ 장소 정보 추출
   └─ PlaceCard 생성

4️⃣ 저장 및 표시
   └─ SwiftData에 저장
   └─ 갤러리/지도에 표시
```

## 2. Google Maps에서 내보내기

### 2.1 방법 1: Google Takeout (공식 방법)

**URL**: https://takeout.google.com

**단계**:
1. Google Account에 로그인
2. "Select data to include" → Google Maps 선택
3. Format: JSON 선택
4. Download (.zip 파일로 다운로드)

**받는 파일 구조**:
```
takeout-{날짜}.zip
└─ Takeout/
   └─ Google Maps/
      ├─ Saved Places.json
      ├─ Reviews.json
      ├─ Saved places.kml (대안 형식)
      └─ ...
```

### 2.2 Saved Places.json 형식

```json
{
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [127.0663, 37.4979]  // [longitude, latitude]
      },
      "properties": {
        "title": "스타벅스 강남역점",
        "address": "서울시 강남구 테헤란로 301",
        "types": ["cafe"],
        "placeID": "ChIJ1234567890",
        "url": "https://www.google.com/maps/place/...",
        "phone": "02-XXXX-XXXX",
        "website": "https://www.starbucks.co.kr/",
        "rating": 4.5,
        "reviews": 280,
        "hours": "오전 10:00 – 오후 10:00",
        "businessStatus": "OPERATIONAL"
      }
    },
    // ... 더 많은 장소들
  ]
}
```

### 2.3 방법 2: Google Maps URL Scheme (직접 연동)

Google Maps 앱에서 공유 버튼 클릭 시 나타나는 URL:

```
https://www.google.com/maps/place/{placeID}
```

**예시**:
```
https://www.google.com/maps/place/ChIJ1234567890/@37.4979,127.0663,15z
```

PlaceCards 앱이 이 URL을 받으면:
1. placeID 추출
2. Google Places API로 상세 정보 조회
3. PlaceCard 생성

## 3. Naver Map에서 내보내기

### 3.1 Naver Map 공식 내보내기 (제한적)

**문제**: Naver Map은 Google Takeout 같은 공식 내보내기 기능이 **없음**

**대안 1: Naver Map URL Scheme**

Naver Map 앱에서 공유 시 URL:
```
nmap://place?id={placeID}&appname=com.example.placecards
```

또는 웹 URL:
```
https://map.naver.com/v5/search/{query}
```

### 3.2 Naver Map의 비공식 내보내기 (스크래핑)

사용자가 Naver Map에서 "내 장소" 목록을 저장할 수 있는 방법:

```
1. Naver Map 앱 → "내 장소" 탭
2. 원하는 폴더 선택
3. 장소 목록 오른쪽 클릭 → "공유"
4. PlaceCards 앱으로 공유
```

**받을 수 있는 형식**: URL 리스트 (텍스트)
```
https://map.naver.com/v5/search/스타벅스 강남역점
https://map.naver.com/v5/search/카페A
...
```

## 4. PlaceCards 앱에서 가져오기 (iOS 구현)

### 4.1 URL Scheme 처리

PlaceCards의 **Info.plist** 설정:

```xml
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLName</key>
        <string>com.placecards.app</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>placecards</string>
        </array>
    </dict>
</array>
```

**사용 예시**:
```
placecards://import/google?placeId=ChIJ1234567890
placecards://import/naver?placeId=12345678
placecards://import/json?data={base64_encoded_json}
```

### 4.2 AppDelegate에서 Deep Link 처리

```swift
// SceneDelegate.swift
func scene(
    _ scene: UIScene,
    openURLContexts URLContexts: Set<UIOpenURLContext>
) {
    guard let url = URLContexts.first?.url else { return }
    
    handleDeepLink(url)
}

private func handleDeepLink(_ url: URL) {
    guard url.scheme == "placecards" else { return }
    
    // URL 구조: placecards://import/{source}?{params}
    let components = URLComponents(url: url, resolvingAgainstBaseURL: true)
    
    guard let host = components?.host else { return }
    
    switch host {
    case "import":
        handleImport(url: url, components: components)
    default:
        break
    }
}

private func handleImport(url: URL, components: URLComponents?) {
    guard let pathComponents = url.pathComponents.dropFirst() as? [String],
          let source = pathComponents.first else { return }
    
    switch source {
    case "google":
        handleGoogleMapImport(components: components)
    case "naver":
        handleNaverMapImport(components: components)
    case "json":
        handleJSONImport(components: components)
    default:
        break
    }
}
```

### 4.3 Google Maps 가져오기

```swift
private func handleGoogleMapImport(components: URLComponents?) {
    // 방법 1: placeId로 Google API 호출
    if let placeId = components?.queryItems?.first(where: { $0.name == "placeId" })?.value {
        Task {
            do {
                let placeDetails = try await googlePlacesService.getDetails(placeId: placeId)
                let placeCard = try await createPlaceCardFromGoogle(placeDetails)
                storageService.save(placeCard)
            } catch {
                print("Error importing from Google: \(error)")
            }
        }
    }
}

private func createPlaceCardFromGoogle(_ details: PlaceDetails) async throws -> PlaceCard {
    var placeCard = PlaceCard(id: UUID().uuidString)
    
    // Google API 응답을 PlaceCard로 매핑
    placeCard.name = details.displayName
    placeCard.address = details.formattedAddress
    placeCard.coordinates = Coordinates(
        latitude: details.location.latitude,
        longitude: details.location.longitude
    )
    placeCard.rating = details.rating
    placeCard.reviewCount = details.userRatingCount
    placeCard.phone = details.nationalPhoneNumber
    placeCard.website = details.websiteUri
    placeCard.hoursDetail = details.regularOpeningHours?.weekdayDescriptions
    placeCard.amenities = details.amenities
    
    // 출처 기록
    let source = SourceRecord(
        id: UUID().uuidString,
        sourceType: .googlePlacesAPI,
        timestamp: Date(),
        confidence: 1.0  // API에서 직접 가져온 것
    )
    placeCard.sources = [source]
    
    return placeCard
}
```

### 4.4 Naver Map 가져오기

```swift
private func handleNaverMapImport(components: URLComponents?) {
    // 방법 1: placeId로 Naver API 호출
    if let placeId = components?.queryItems?.first(where: { $0.name == "placeId" })?.value {
        Task {
            do {
                let placeDetails = try await naverProxyService.getDetails(placeId: placeId)
                let placeCard = try await createPlaceCardFromNaver(placeDetails)
                storageService.save(placeCard)
            } catch {
                print("Error importing from Naver: \(error)")
            }
        }
    }
}

private func createPlaceCardFromNaver(_ details: NaverPlaceDetails) async throws -> PlaceCard {
    var placeCard = PlaceCard(id: UUID().uuidString)
    
    // Naver API 응답을 PlaceCard로 매핑
    placeCard.name = details.title
    placeCard.address = details.roadAddress ?? details.address
    placeCard.coordinates = Coordinates(
        latitude: Double(details.mapy) ?? 0,
        longitude: Double(details.mapx) ?? 0
    )
    placeCard.phone = details.phone
    placeCard.website = details.website
    
    // Naver는 평점/리뷰가 없으므로 Google API로 보강
    if let googleResults = try? await googlePlacesService.search(
        query: details.title,
        languageCode: "ko"
    ),
       let googleResult = googleResults.first {
        placeCard.rating = googleResult.rating
        placeCard.reviewCount = googleResult.reviewCount
        placeCard.hoursDetail = googleResult.hoursDetail
        placeCard.amenities = googleResult.amenities
        placeCard.website = googleResult.website ?? placeCard.website
    }
    
    // 출처 기록
    placeCard.sources = [
        SourceRecord(
            id: UUID().uuidString,
            sourceType: .naverAPI,
            timestamp: Date(),
            confidence: 1.0
        )
    ]
    
    return placeCard
}
```

### 4.5 JSON 파일 가져오기 (Google Takeout)

```swift
private func handleJSONImport(components: URLComponents?) {
    // 방법: base64 인코딩된 JSON 데이터
    if let encodedJSON = components?.queryItems?.first(where: { $0.name == "data" })?.value,
       let jsonData = Data(base64Encoded: encodedJSON) {
        Task {
            do {
                let decoder = JSONDecoder()
                let response = try decoder.decode(GoogleMapsTakeoutResponse.self, from: jsonData)
                
                for feature in response.features {
                    let placeCard = try createPlaceCardFromGeoJSON(feature)
                    storageService.save(placeCard)
                }
            } catch {
                print("Error decoding JSON: \(error)")
            }
        }
    }
}

// Google Takeout 형식 파싱
struct GoogleMapsTakeoutResponse: Decodable {
    let features: [GeoJSONFeature]
}

struct GeoJSONFeature: Decodable {
    let geometry: Geometry
    let properties: PlaceProperties
}

struct Geometry: Decodable {
    let coordinates: [Double]  // [longitude, latitude]
}

struct PlaceProperties: Decodable {
    let title: String
    let address: String?
    let types: [String]?
    let placeID: String?
    let rating: Double?
    let reviews: Int?
    let phone: String?
    let website: String?
    let hours: String?
}

private func createPlaceCardFromGeoJSON(_ feature: GeoJSONFeature) throws -> PlaceCard {
    var placeCard = PlaceCard(id: UUID().uuidString)
    
    placeCard.name = feature.properties.title
    placeCard.address = feature.properties.address ?? ""
    
    let coords = feature.geometry.coordinates
    placeCard.coordinates = Coordinates(
        latitude: coords[1],
        longitude: coords[0]
    )
    
    placeCard.rating = feature.properties.rating
    placeCard.reviewCount = feature.properties.reviews
    placeCard.phone = feature.properties.phone
    placeCard.website = feature.properties.website
    
    // 출처 기록
    placeCard.sources = [
        SourceRecord(
            id: UUID().uuidString,
            sourceType: .googlePlacesAPI,
            timestamp: Date(),
            confidence: 0.95  // Google Takeout 내보내기
        )
    ]
    
    return placeCard
}
```

### 5.2 파일 선택 UI

```swift
import DocumentPickerViewController

struct FileImportView: View {
    @State private var isDocumentPickerPresented = false
    @ObservedObject var viewModel: PlaceCardCreationViewModel
    
    var body: some View {
        VStack {
            Button("Google Takeout JSON 파일 선택") {
                isDocumentPickerPresented = true
            }
        }
        .fileImporter(
            isPresented: $isDocumentPickerPresented,
            allowedContentTypes: [.json],
            onCompletion: { result in
                switch result {
                case .success(let url):
                    handleFileImport(url: url)
                case .failure(let error):
                    print("Error: \(error)")
                }
            }
        )
    }
    
    private func handleFileImport(url: URL) {
        Task {
            do {
                let data = try Data(contentsOf: url)
                let decoder = JSONDecoder()
                let response = try decoder.decode(
                    GoogleMapsTakeoutResponse.self,
                    from: data
                )
                
                for feature in response.features {
                    let placeCard = try viewModel.createPlaceCardFromGeoJSON(feature)
                    try viewModel.storageService.save(placeCard)
                }
                
            } catch {
                print("Error importing file: \(error)")
            }
        }
    }
}
```

## 6. 공유 버튼 기반 가져오기

### 6.1 iOS Share Sheet 통합

Google Maps나 Naver Map 앱에서 "공유" → "PlaceCards" 선택

**PlaceCards에서 처리**:

```swift
// 1. Google Maps 공유 URL 수신
// https://www.google.com/maps/place/ChIJ1234567890

// 2. Naver Map 공유 URL 수신
// https://map.naver.com/v5/search/place-name

// 3. SceneDelegate에서 처리
func scene(
    _ scene: UIScene,
    openURLContexts URLContexts: Set<UIOpenURLContext>
) {
    for context in URLContexts {
        let url = context.url
        
        if url.host?.contains("google.com") == true {
            handleGoogleMapsURL(url)
        } else if url.host?.contains("naver.com") == true {
            handleNaverMapURL(url)
        }
    }
}

private func handleGoogleMapsURL(_ url: URL) {
    // URL 예: https://www.google.com/maps/place/강남역/@37.4979,127.0663
    if let placeId = extractGooglePlaceID(from: url) {
        Task {
            let details = try await googlePlacesService.getDetails(placeId: placeId)
            let placeCard = try await createPlaceCardFromGoogle(details)
            storageService.save(placeCard)
        }
    }
}

private func extractGooglePlaceID(from url: URL) -> String? {
    // URL 파싱으로 placeId 추출
    // ChIJ1234567890 형태
    let pattern = "ChIJ[a-zA-Z0-9_-]+"
    if let regex = try? NSRegularExpression(pattern: pattern) {
        let range = NSRange(url.absoluteString.startIndex..., in: url.absoluteString)
        if let match = regex.firstMatch(in: url.absoluteString, range: range) {
            return (url.absoluteString as NSString).substring(with: match.range)
        }
    }
    return nil
}
```

## 7. 배치 가져오기 (여러 장소)

### 7.1 Google Takeout 일괄 임포트

```swift
struct BatchImportView: View {
    @State private var isDocumentPickerPresented = false
    @State private var importProgress: Double = 0
    @State private var totalPlaces: Int = 0
    @ObservedObject var viewModel: BatchImportViewModel
    
    var body: some View {
        VStack {
            if importProgress > 0 && importProgress < 1 {
                ProgressView(value: importProgress)
                Text("가져오는 중... (\(Int(importProgress * 100))%)")
            }
            
            Button("Google Takeout 파일 선택") {
                isDocumentPickerPresented = true
            }
        }
        .fileImporter(
            isPresented: $isDocumentPickerPresented,
            allowedContentTypes: [.json],
            onCompletion: { result in
                if case .success(let url) = result {
                    Task {
                        await handleBatchImport(url: url)
                    }
                }
            }
        )
    }
    
    private func handleBatchImport(url: URL) async {
        do {
            let data = try Data(contentsOf: url)
            let decoder = JSONDecoder()
            let response = try decoder.decode(
                GoogleMapsTakeoutResponse.self,
                from: data
            )
            
            totalPlaces = response.features.count
            
            for (index, feature) in response.features.enumerated() {
                let placeCard = try viewModel.createPlaceCardFromGeoJSON(feature)
                try viewModel.storageService.save(placeCard)
                
                importProgress = Double(index + 1) / Double(totalPlaces)
                
                // UI가 반응적이도록 짧은 지연
                try? await Task.sleep(nanoseconds: 10_000_000)  // 0.01초
            }
            
        } catch {
            print("Batch import error: \(error)")
        }
    }
}
```
