# PlaceCards 언어/로컬라이제이션 조사 보고서

## 개요

사용자가 제시한 3가지 언어 관련 이슈를 조사했습니다:
1. 앱 UI 메뉴: 영어 기본 + 사용자 선택에 따라 변경
2. 상호명/주소: 영어와 현지 언어 모두 정확히 제공되는지 확인
3. AI OCR 한국 환경: 한국어 입력 + Google API 한국어 출력 확인

## 1. Google Places API의 다국어 지원

### 1.1 API 언어 설정 (languageCode 파라미터)

Google Places API는 **`languageCode` 파라미터**로 언어 지정 가능합니다.

```swift
// Swift 예시
let request = URLRequest(url: URL(string: "https://places.googleapis.com/v1/places:searchText")!)
// 요청 본문
{
    "textQuery": "coffee shop",
    "languageCode": "ko"  // ← 한국어 지정
}
```

### 1.2 지원하는 언어 코드

Google Places API가 공식 지원하는 주요 언어:
- **한국어**: `ko`
- **영어**: `en`
- **중국어 (간체)**: `zh-CN`
- **중국어 (번체)**: `zh-TW`
- **일본어**: `ja`
- **스페인어**: `es`
- **프랑스어**: `fr`
- **독일어**: `de`
- **이탈리아어**: `it`
- 등 200+ 언어 지원

### 1.3 Google API 응답의 다언어 처리

**중요**: Google Places API 응답에서 상호명과 주소는 **languageCode 파라미터로 지정한 언어로 반환**됩니다.

### 1.4 주소 지역화 전략 (중요!)

Google Places API 문서에 따르면:

> "API는 사용자와 현지인 모두에게 읽기 좋은 주소를 제공하려고 노력합니다. 
> 거리 주소는 현지 언어로 반환되고, 필요시 사용자가 읽을 수 있는 스크립트로 음역됩니다. 
> 다른 주소는 선호 언어로 반환됩니다. 주소 구성 요소는 모두 동일한 언어로 반환됩니다."

**예시**:
```

거리 주소: "301 Teheran-ro" (한국 도로 이름을 영문 음역)

```

## 2. Naver Map API의 다국어 지원

### 2.1 Naver API 언어 설정

Naver Map API는 요청 시점에 **`language` 파라미터**로 언어 지정:

```javascript
// Node.js 백엔드 프록시 예시
app.post('/api/naver/search', async (req, res) => {
    const { query, language } = req.body;
    
    const naverResponse = await axios.get(
        'https://openapi.naver.com/v1/search/local.json',
        {
            headers: {
                'X-Naver-Client-Id': process.env.NAVER_CLIENT_ID,
                'X-Naver-Client-Secret': process.env.NAVER_CLIENT_SECRET
            },
            params: {
                query: query,
                display: 10,
                language: language || 'ko'  // ← 기본값: 한국어
            }
        }
    );
    
    res.json(naverResponse.data);
});
```

### 2.2 지원하는 언어 (Naver Map API)

Naver Map API 공식 문서:
- **한국어**: `ko` (기본값)
- **영어**: `en`
- **중국어 (간체)**: `zh-CN`
- **중국어 (번체)**: `zh-TW`
- **일본어**: `ja`

### 2.3 Naver API 응답 형식

```json
// language: "ko" 요청 시
{
  "items": [
    {
      "title": "스타벅스 강남역점",
      "address": "서울 강남구 테헤란로 301",
      "roadAddress": "서울시 강남구 테헤란로 301",
      "mapx": "127.0663",
      "mapy": "37.4979"
    }
  ]
}
```

```json
// language: "en" 요청 시
{
  "items": [
    {
      "title": "Starbucks Gangnam Station",
      "address": "Gangnam-gu, Seoul",
      "roadAddress": "301 Teheran-ro, Gangnam-gu, Seoul",
      "mapx": "127.0663",
      "mapy": "37.4979"
    }
  ]
}
```

### ⚠️ 주의사항: Naver의 한계

1. **영문 주소의 정확도**: Naver는 한국 로컬 지명을 영문으로 변환할 때 일관성이 부족할 수 있음
2. **소규모 장소**: 한국 로컬 카페/식당은 영문 데이터가 없을 수 있음
3. **필드 제한**: Google처럼 평점, 리뷰, 영업시간 같은 상세정보 미제공

### ✅ 결론: Naver는 **기본적인 다언어 지원** (Google 수준은 아님)

### 5.1 앱 메뉴 로컬라이제이션 (영어 + 다언어)

```swift
// 앱의 기본 구조: 영어 기반 + 사용자 선택에 따라 변경

@AppStorage("selectedLanguage") var selectedLanguage: String = "en"

enum Language: String, CaseIterable {
    case english = "en"
    case korean = "ko"
    case chinese = "zh-CN"
    case japanese = "ja"
    
    var displayName: String {
        switch self {
        case .english:
            return "English"
        case .korean:
            return "한국어"
        case .chinese:
            return "中文"
        case .japanese:
            return "日本語"
        }
    }
}

// Localization strings
struct LocalizedStrings {
    static func getString(_ key: String, language: String) -> String {
        let bundle = Bundle(path: Bundle.main.path(forResource: language, ofType: "lproj") ?? "")
        return NSLocalizedString(key, bundle: bundle ?? .main, comment: "")
    }
}

// 사용 예시
struct SettingsView: View {

        .onChange(of: selectedLanguage) { _ in
```

### 5.2 상호명/주소 다언어 처리 전략

```swift
// PlaceCard 모델에 다언어 정보 저장
struct PlaceCard: Codable {
    let id: String
    
    // 다언어 상호명
    var nameByLanguage: [String: String] = [:]  // {"ko": "스타벅스", "en": "Starbucks", ...}
    
    // 다언어 주소
    var addressByLanguage: [String: String] = [:]  // {"ko": "서울시...", "en": "Seoul..."}
    
    // 현재 선택된 언어로 표시될 값
    var displayName: String {
        let currentLanguage = UserDefaults.standard.string(forKey: "selectedLanguage") ?? "en"
        return nameByLanguage[currentLanguage] ?? nameByLanguage["en"] ?? name
    }
    
    var displayAddress: String {
        let currentLanguage = UserDefaults.standard.string(forKey: "selectedLanguage") ?? "en"
        return addressByLanguage[currentLanguage] ?? addressByLanguage["en"] ?? address
    }
    
    // 기본값 (역호환성)
    var name: String
    var address: String
}

// API 호출 시 여러 언어로 동시 요청
func searchPlaceInMultipleLanguages(
    query: String,
    languages: [String] = ["ko", "en"]
) async throws -> PlaceCard {
    var placeCard = PlaceCard(id: UUID().uuidString, name: "", address: "")
    
    // 각 언어로 API 호출
    for language in languages {
        let result = try await googleService.search(
            query: query,
            languageCode: language
        )
        
        if !result.isEmpty {
            let place = result[0]
            placeCard.nameByLanguage[language] = place.displayName
            placeCard.addressByLanguage[language] = place.address
        }
    }
    
    // 기본값 설정 (한국어 우선, 없으면 영어)
    placeCard.name = placeCard.nameByLanguage["ko"] ?? placeCard.nameByLanguage["en"] ?? ""
    placeCard.address = placeCard.addressByLanguage["ko"] ?? placeCard.addressByLanguage["en"] ?? ""
    
    return placeCard
}
```

### 5.4 Google Places API 호출 (다언어)

```swift
class GooglePlacesService {
    func search(
        query: String,
        languageCode: String = "en"
    ) async throws -> [PlaceSearchResult] {
        let url = URL(string: "https://places.googleapis.com/v1/places:searchText")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue(apiKey, forHTTPHeaderField: "X-Goog-Api-Key")
        
        let body = [
            "textQuery": query,
            "languageCode": languageCode  // ← 언어 파라미터
        ]
        
        request.httpBody = try JSONEncoder().encode(body)
        
        let (data, _) = try await URLSession.shared.data(for: request)
        let response = try JSONDecoder().decode(GooglePlacesResponse.self, from: data)
        
        return response.places.map { place in
            PlaceSearchResult(
                id: place.id,
                name: place.displayName.text,
                address: place.formattedAddress,
                language: place.displayName.languageCode,
                // ... 기타
            )
        }
    }
}
```

```
- 앱 메뉴: 영어 고정 (한글 미지원)
- API: Google (한국어), Naver (한국어)
- AI OCR: 한국어 프롬프트 사용
- 상호명/주소: 한국어만 저장
```

### Phase 2: 다언어 확대 (v1.1)
```
- 앱 메뉴: ko, en 지원
- PlaceCard: 다언어 저장 (nameByLanguage, addressByLanguage)
- API: Google (여러 언어), Naver (한글/영어만)
- 사용자 설정: 언어 선택 화면
```

### Phase 3: 글로벌 확대 (v1.2+)
```
- 앱 메뉴: 중국어, 일본어 추가
- PlaceCard: 4개 언어 모두 지원
- API: Google (모든 언어), Naver (제한적)
- 지역별 최적화: 중국/일본 사용자 대응
```
